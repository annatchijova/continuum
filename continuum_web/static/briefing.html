DETERMINISTIC CORE / AUTHORITY

Every consequential decision is reproducible.

The offline core classifies documents, retrieves and ranks evidence, enforces heir policies, and verifies the audit trail. It never depends on a model to make a decision.

  • Classification and ranking are deterministic
  • Access policy is evaluated locally
  • Integrity verification is independent of the UI

03 / THE TRUST PROTOCOL

04 / WHY CHATGPT BELONGS HERE

Compassion needs language.
Trust needs limits.

Only after local retrieval selects evidence, a person can opt in to an OpenAI Agents SDK narration. The agent is stateless, has no vault tools, and its request outcome is locally audited without plaintext.
