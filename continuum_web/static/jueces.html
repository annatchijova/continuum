03 / EL PROTOCOLO DE CONFIANZA

No es una promesa.
Es un sistema verificable.

El producto está diseñado para que una interfaz útil nunca se convierta en una autoridad sin rendición de cuentas.

A

Cifrado AES-256-GCM

El vault y los artefactos archivados usan cifrado autenticado. Los nuevos workspaces Studio también activan cifrado de base en reposo antes de su primera captura.

CONFIDENCIALIDAD + AUTENTICIDAD
B

Cadena de auditoría SHA-256

Las operaciones relevantes se agregan a una cadena detectable ante alteraciones. Una clave HMAC opcional fortalece la resistencia a reescrituras por atacantes con acceso al storage.

PROCEDENCIA + EVIDENCIA DE ALTERACIÓN
C

Continuidad gobernada por políticas

El dueño elige condiciones de liberación para herederos. El núcleo las evalúa localmente; la interfaz sólo puede mostrar el resultado.

AUTORIDAD DE ACCESO LOCAL

04 / POR QUÉ CHATGPT PERTENECE AQUÍ

La compasión necesita lenguaje.
La confianza necesita límites.

Continuum usa OpenAI Agents SDK y GPT-5.6 sólo después de que el retrieval local ya seleccionó la evidencia. Una persona debe dar opt-in explícito antes de que los extractos seleccionados salgan del dispositivo.
