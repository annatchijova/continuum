02 / THE PRODUCT ARCHITECTURE

One source of truth.

01

DETERMINISTIC CORE / AUTHORITY

Every consequential decision is reproducible.

The offline core classifies documents with keywords and regex, retrieves and ranks evidence, enforces heir policies, and verifies the audit trail. It never depends on a model to make a decision.

  • Classification and ranking are deterministic
  • Access policy is evaluated locally
  • Integrity verification is independent of the UI

03 / THE TRUST PROTOCOL

Not a promise.
A verifiable system.

The product is designed so that a helpful interface never becomes an unaccountable authority.

A

AES-256-GCM encryption

The vault and archived artifacts use authenticated encryption. New Studio workspaces also enable database-at-rest encryption before their first capture.

CONFIDENTIALITY + AUTHENTICITY
B

SHA-256 audit chain

Meaningful operations are appended to a tamper-evident chain. An optional HMAC key strengthens resistance to chain rewriting by an attacker with storage access.

PROVENANCE + TAMPER EVIDENCE
C

Policy-gated continuity

The owner chooses heir release conditions. The core evaluates them locally; the interface can only show the result.

LOCAL ACCESS AUTHORITY

04 / WHY CHATGPT BELONGS HERE

Compassion needs language.
Trust needs limits.

Continuum uses the OpenAI Agents SDK and GPT-5.6 only after local retrieval has already selected the evidence. A person must explicitly opt in before selected excerpts leave the device.

THE AGENT IS STATELESS · SDK TRACING DISABLED · RESPONSES STORAGE DISABLED
